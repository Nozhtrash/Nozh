# 🇬🇧 English

## What is NOZH?

**NOZH** (Now Only Zen HUD) is an **intelligent, event-driven performance orchestrator** for Minecraft that automatically optimizes your game settings in real-time. Unlike traditional optimization mods that use static configurations, NOZH implements a sophisticated **Mathematical Optimization Core** with machine learning capabilities (Kalman Filters + PID Controllers) to adapt to your specific hardware and gameplay scenarios.

Whether you have a $300 potato laptop or a $5000 4090 beast, NOZH extracts every drop of performance.

### 🎯 Core Philosophy

- **Adaptive**: NOZH creates a custom profile for your hardware (Potato Mode to Ultra Quality).
- **Intelligent**: Detecting scenarios (Combat, Building, Exploring) and adjusting settings instantly.
- **Compatible**: Built-in knowledge base of 50+ mods (Sodium, Lithium, Create, etc.) to prevent conflicts.
- **Transparent**: Professional HUD and analytics show you exactly what's happening.

---

## ✨ Features (v0.3.0 "Ultimate")

### ⚡ Phase 1: Mathematical Core

- **Kalman Filter**: Predicts frametime spikes before they happen.
- **PID Controller**: Smoothly adjusts render distance without stuttering.
- **Resource Budget**: Allocates GPU power where it matters most (Entities vs Terrain).

### 🥔 Phase 2: Potato Mode (Low-End PC Support)

- **5 Optimization Levels**: From `LEVEL_1` (Light) to `SURVIVAL` (Extreme).
- **Memory Optimizer**: Intelligent RAM cleaning for 4GB/8GB systems.
- **Startup Optimizer**: Reduces game load times by up to 40%.

### 📊 Phase 3: Professional Analytics

- **Session Analyzer**: Detailed reports on your gameplay performance.
- **Diagnostic Tool**: Export comprehensive system health checks (Markdown/JSON).
- **Performance Logger**: Track bottlenecks with precision.

### 🔌 Phase 4: Smart Compatibility

- **Mod Knowledge Base**: Knows 50+ mods and automatically adjusts to them.
- **Conflict Resolver**: Fixes incompatibility issues without user intervention.
- **Modpack Profiler**: Detects if you're playing a Tech, Magic, or Vanilla+ pack.

### 👁️ Phase 5: Professional HUD

- **MSI Afterburner Style**: Real-time frametime graphs and hardware stats.
- **6 Presets**: Minimal, Gamer, Analyst, Streamer, Developer, Custom.
- **Smart Suggestions**: Non-intrusive tips to double your FPS.

### 🌍 Phase 6: Global & Accessible

- **15 Languages**: English, Spanish, Portuguese, French, German, Russian, Chinese, Japanese, and more.
- **9Config Presets**: One-click setup for any scenario (Recording, PvP, Potato, etc.).
- **Auto-Updater**: Never miss a performance patch.

A diferencia de los mods tradicionales, NOZH utiliza un **Núcleo de Optimización Matemático** (Filtros de Kalman + Controladores PID) para adaptarse a tu hardware específico.

Ya tengas una laptop "patata" de $300 o una bestia con 4090, NOZH extrae cada gota de rendimiento.

- **Adaptativo**: Crea un perfil único para tu hardware.
