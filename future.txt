## 🧠 LÓGICA INTELIGENTE

### Decision Making:
```
1. Capturar snapshot ANTES
2. Aplicar acción
3. Esperar ventana observación (10-30s)
4. Capturar snapshot DESPUÉS
5. Comparar métricas:
   - Si P95_después >= P95_antes: ROLLBACK
   - Si P95_después < P95_antes: SUCCESS
6. Guardar en SessionLearning
7. Nunca repetir acciones FAILED
```

### Learning Strategy:
```
Confidence Score = 
    (historical_success * 0.65) +
    (learned_confidence * 0.30) +
    (environment_stability * 0.05)

Si confidence < 0.3: SKIP
Si confidence >= 0.7: PRIORITIZE

Ranking = success_rate * (1 + avg_fps_gain)
```

### Scenario Profiles:
```
COMBAT:
- NO tocar render distance
- Reducir partículas agresivamente
- Mantener FPS alto (no cap)
- Quitar sombras

BUILDING:
- Reducir BlockEntity distance
- Cap FPS a 60
- Mantener calidad visual moderada

AFK:
- TODAS las optimizaciones agresivas
- FPS cap a 30
- Pausar IA de mobs
- Render distance = 4
- Simulation distance = 2

EXPLORING:
- Bajar render distance 1-2 chunks temporal
- Reducir particles
- Priorizar chunk loading
```
