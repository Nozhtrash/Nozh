## 🧠 LÓGICA INTELIGENTE MEJORADA

### Decision Making v0.3.1:
```
1. Capturar snapshot ANTES
2. Calcular confianza bayesiana con:
   - Prior: datos históricos
   - Evidence: precisión reciente de predicciones
   - Modifier: escenario actual (combate=0.85, idle=1.1)
   - Bonus: racha de éxitos
3. Verificar EMA trend (fast > slow = degradación)
4. Verificar micro-stutters y estabilidad
5. Solo actuar si confianza > 0.7 Y múltiples señales confirman
6. Aplicar acción
7. Esperar ventana observación (10-30s)
8. Validar mejora estadísticamente:
   - Requiere 3+ muestras sostenidas
   - p95 improvement > 0.5ms
   - Significance score > 0.7
9. Si válido: SUCCESS, actualizar SessionLearning
10. Si no válido: ROLLBACK, registrar fallo
```

### Learning Strategy v0.3.1:
```
Bayesian Confidence Score = 
    bayesianUpdate(prior, predictionAccuracy) *
    scenarioModifier *
    (1 + streakBonus) *
    decayFactor *
    antiFlappingPenalty

Quality Recovery:
- Umbral para bajar: targetFrameMs + sensitivity
- Umbral para subir: targetFrameMs - (sensitivity * 1.5) <- HISTÉRESIS
- Rachas requeridas: 2 para bajar, 4 para subir
- Intervalo mínimo: 10s bajar, 30s subir
- Estabilidad requerida: 60s sin romper umbral
```
